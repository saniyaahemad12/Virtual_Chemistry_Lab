# 🧪 Virtual Chemistry Lab

## Overview

Virtual Chemistry Lab is an interactive web application that allows users to simulate chemistry experiments in a safe virtual environment. It aims to provide students, educators, and enthusiasts with a hands-on experience to explore chemical reactions, lab procedures, and experiment outcomes without the risks of a physical lab.

This project combines web development with interactive simulations to make learning chemistry engaging and accessible.

## Features

- Interactive Experiments: Perform common chemistry experiments virtually.

- Realistic Simulation: Simulates chemical reactions with visual feedback.

- Safety First: No risk of handling real chemicals.

- Educational: Provides theory, instructions, and results for each experiment.

- User-Friendly Interface: Easy navigation with drag-and-drop components for experiments.

- Frontend: HTML, CSS, JavaScript

- Backend: Flask (Python)
